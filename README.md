# spine-canvas-rebuild

This repository is a personal rebuild of the discontinued **Spine AI Canvas/Swarm** product: an infinite canvas on which typed blocks are generated by AI agents, wired together as a directed acyclic graph (DAG), and executed as runs that emit real downloadable artifacts.

## What's in this repo

- **[SPEC.md](./SPEC.md)** — the full implementation-ready technical build specification. This is the primary reference document and covers system architecture, the Postgres/Supabase data model, specifications for all 17 block types (plus 5 app-only surfaces), the multi-model orchestration layer, the Swarm Mode orchestrator, the Deep Research block, the infinite canvas UI approach, the integrations/MCP layer, the tech stack and environment variables, and a 4-phase build roadmap with a known-gaps ledger.
- **[dashboard/](./dashboard)** — a self-contained interactive HTML dashboard that serves as the visual reference for the block-type system and the phased build roadmap. Open `dashboard/index.html` directly in a browser to explore all block types (filterable by category) and the 4-phase roadmap with progress tracking.
- **Starter scaffold** (`/app`, `/lib`, `/supabase`, `/components`, `/public`) — empty placeholder directories matching the Next.js 14 App Router + TypeScript + Supabase + Tailwind stack described in the spec, ready to be filled in during Phase 1 of the build roadmap.

## Target stack

Next.js 14 (App Router) + TypeScript + Supabase (Auth, Postgres, Storage, Realtime) + Tailwind CSS, deployed on Vercel, with model routing across OpenAI, Anthropic, Google, and OpenRouter.

See [SPEC.md](./SPEC.md) for full details.
